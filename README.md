# آرایشگاه مردانه سلطان — دموی سایت

دموی سایت آرایشگاه مردانه با تم لوکس مشکی/طلایی، کاملاً فارسی (RTL)، فقط HTML / CSS / JS ساده — بدون فریمورک یا فرآیند بیلد، آماده‌ی دیپلوی روی GitHub Pages.

## ساختار پروژه
```
.
├── index.html       صفحه اصلی
├── services.html    لیست کامل قیمت خدمات (با فیلتر دسته‌بندی)
├── gallery.html     گالری تصاویر کارها (با فیلتر دسته‌بندی)
├── barbers.html     معرفی آرایشگران
├── booking.html     رزرو نوبت آنلاین (فرم کامل + نقشه)
└── static/
    ├── css/style.css
    ├── js/main.js
    └── img/
```

## دیپلوی روی GitHub Pages
1. محتوای این پوشه رو با همین ساختار (فایل‌های html در ریشه) به یک ریپازیتوری جدید در گیت‌هاب push کنید.
2. Settings → Pages
3. Source: `Deploy from a branch` → برنچ `main` و پوشه‌ی `/ (root)` → Save
4. بعد از چند دقیقه، سایت روی آدرس `https://<username>.github.io/<repo-name>/` در دسترسه.

## نکات مهم
- تصاویر گالری فعلاً با گرادیان رنگی CSS جایگزین شدن (چون عکس واقعی در دسترس نبود). عکس‌های واقعی رو داخل `static/img/` بذارید و در `gallery.html` و `index.html` با `<img src="static/img/...">` جایگزین `div.gallery-item` کنید.
- فرم رزرو نوبت (`booking.html`) فقط سمت کلاینت اعتبارسنجی می‌شه و داده‌ای به سرور ارسال نمی‌کنه، چون GitHub Pages فقط فایل استاتیک سرو می‌کنه. برای ثبت واقعی نوبت، از سرویس‌هایی مثل Formspree، Netlify Forms یا یک بک‌اند اختصاصی (و یک پنل مدیریت نوبت‌ها) استفاده کنید.
- نقشه‌ی صفحه‌ی رزرو، یک embed عمومی گوگل‌مپ روی «تهران» است؛ آدرس دقیق خودتون رو در URL آیفریم داخل `booking.html` جایگزین کنید.
- تمام قیمت‌ها، اسامی آرایشگران و اطلاعات تماس صرفاً نمونه هستند؛ قبل از استفاده واقعی جایگزینشون کنید.
